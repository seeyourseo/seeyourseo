Jev SEO review: a local audit CLI with model-assisted page judgments

jev-seo combines a local website crawler, deterministic SEO checks, PageSpeed data, and typed judgments from Jev, TypeSafe's model. It produces PDF, Excel, and Markdown reports from one audit. SeeYourSEO is a hosted crawler and report workflow that needs only a browser and a site URL to start.

Disclosure and method: SeeYourSEO is our product, so we include it as a comparator. This is a source-and-documentation review of jev-seo commit 55a184a, checked on 2026-10-27. We reviewed the crawler, checks, model and data-provider clients, report code, CLI, and project documentation. We did not install the project or run an audit, so this is not a performance benchmark.

A complete local report pipeline

The CLI begins with robots.txt and sitemaps, then follows internal links breadth-first. The crawler records redirects separately, checks links, inspects robots and security headers, and can use optional Playwright Chromium to render JavaScript pages. The code includes a private-network guard for the requested host and redirect hops, and it retries failed HEAD checks with GET before reporting a link as broken.

After crawling, 52 rule checks cover areas such as indexing, metadata, content, links, structured data, AI crawler access, performance, and security. The report layer turns the same audit data into three useful outputs: a designed PDF, an Excel workbook with an editable action tracker, and Markdown with charts. This is a strong fit for consultants or teams that need a deliverable they can save, share, and track locally.

Jev adds typed judgments about page type, search intent, importance, helpfulness, specificity, trust, citability, and title and description fit. The code keeps probabilities and marks less decisive answers for review. Jev is a model judge of supplied evidence, not a search engine data source; its score should guide review rather than be read as a prediction of rankings or traffic.

Cost and data boundaries

The Python crawler, rules, scoring, and report generation run locally. The standard audit can run without a TypeSafe key, but the Jev judgment sections are skipped. With Jev enabled, the code sends page and site context to the TypeSafe API. PageSpeed Insights requests send the tested URLs to Google's API. The optional --full mode sends domain and keyword research requests to DataForSEO.

The repository documents a Jev spend cap, a separate DataForSEO cap for full mode, and a cost ledger in each report. Its README estimates a small Jev charge per audit and about $0.30 for a typical full DataForSEO run; actual usage depends on pages, requests, and provider billing. PageSpeed Insights is described as free, though an API key may help with rate limits. Check the providers' current terms and pricing before enabling paid integrations.

Local output keeps the generated files on your machine, but local execution does not mean every piece of audit data stays local: model judgments, PageSpeed checks, and optional DataForSEO queries use their respective external APIs. The project describes key lookup through environment variables or .env files and a doctor command that reports whether keys exist without printing their values.

Useful measurement notes, with limits

jev-seo's repository includes an evaluation write-up rather than presenting its scores as established truth. It reports repeatability checks on 59 pages and agreement comparisons with a second model judge. The project explicitly says that second judge is not human-labelled ground truth, and that the accuracy of its semantic judgments has not yet been established against human labels. The README also warns that PageSpeed lab scores vary, field data may be absent, and large sites are sampled at the page cap.

Those caveats are helpful. The deterministic crawl and rule findings are easier to verify than judgments about helpfulness, trust, or content quality. In practice, inspect the cited page evidence and review uncertain model answers before turning them into client recommendations.

Jev SEO compared with SeeYourSEO

jev-seo offers more control over the audit pipeline and the exported deliverables. You can run it locally, adjust page and time limits, rescore saved data without another crawl, and hand clients a PDF and action workbook. Its full mode adds a broad external data layer, but requires provider credentials and incurs usage costs.

SeeYourSEO is simpler to start: enter a site URL in the browser and inspect the resulting site report. There is no local Python environment or provider setup for a basic hosted scan. The free hosted tier scans up to 20 pages; paid one-time plans allow larger scans. The public MIT-licensed edition is also available for self-hosting.

Choose jev-seo if you want local execution, downloadable client reports, a spreadsheet for tracking fixes, and optional keyword or backlink research. Choose SeeYourSEO if you want a quick browser-based crawl without installing a Python toolchain. We have not run both products against the same site, so we cannot compare their coverage, speed, finding accuracy, or report quality from direct measurements.

Who should try jev-seo?

  • SEO consultants who deliver reports and action plans to clients.
  • Teams comfortable with Python, local files, and checking model-assisted judgments against cited evidence.
  • Users who need optional keyword, ranking, competitor, and backlink research and can manage separate provider accounts and budgets.

If your main need is an easy hosted crawl with no local setup, SeeYourSEO is a more direct starting point. If your work depends on live rank tracking or Search Console, remember that jev-seo describes itself as an audit tool and does not replace those products.
