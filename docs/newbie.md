新手看不懂的通常不是问题本身,而是**术语和判断规则**。下面是类似"全站词"的概念,每个都可以在工具里做成"名称 + 一句话解释 + 可视化"。

## 内容类

| 概念 | 一句话解释 | 可视化建议 |
|---|---|---|
| 全站词 | 几乎每页都有、不能区分页面的词 | 词云里灰掉,标注"出现在 85% 页面" |
| 模板文本 | 导航、页脚、弹窗里的重复文字 | 页面上高亮哪些块被判为模板 |
| 净正文 | 去掉模板后真正的内容 | 字数对比:总字数 vs 净正文 |
| 薄内容 | 正文太少,搜索引擎认为没价值 | 页面按净正文字数排序的柱状图 |
| 近似重复 | 两页内容几乎一样 | 并排 diff,标出不同的段落 |
| 关键词自相残杀 | 多个页面争同一个词 | 词 → 页面的二分图,多线连到同一词就是冲突 |
| 栏目通用词 | 某个目录下页面都有的词 | 按目录分组的词频热力图 |
| 主关键词位置 | 词是否出现在 title、H1、首段、URL | 每页一行的对勾矩阵 |

## 抓取与结构

| 概念 | 一句话解释 | 可视化建议 |
|---|---|---|
| 孤儿页 | 站内没有任何链接指向它 | 站点链接图里的孤立节点 |
| 点击深度 | 从首页点几次才到这页 | 层级柱状图,深度超过 3 标红 |
| 重定向链 | A→B→C 多跳才到终点 | 链式箭头图,标出每跳状态码 |
| 爬虫陷阱 | 参数组合无限生成 URL(日历、筛选) | URL 模式聚类,显示"这一类有 N 万个" |
| URL 规范化 | 同一页面的多种写法(斜杠、大小写、参数) | 同组 URL 折叠展示 |
| 抓取预算 | 搜索引擎愿意在你站上花多少抓取量 | 抓取量花在有价值页面 vs 垃圾页面的饼图 |

## 索引控制

| 概念 | 一句话解释 | 可视化建议 |
|---|---|---|
| canonical | 告诉搜索引擎"哪个才是正版" | 多页指向同一正版的树状图 |
| noindex | 要求搜索引擎不收录 | 页面状态标签,冲突时标红 |
| robots 封禁 | 禁止抓取某路径 | 路径树上标出被封的分支 |
| 信号矛盾 | 在 sitemap 里却被 noindex 或被 robots 封 | 矛盾清单,每项两个冲突来源 |
| 软 404 | 页面返回 200,内容却是"未找到" | 与正常页面内容对比 |

## 链接

| 概念 | 一句话解释 | 可视化建议 |
|---|---|---|
| 内链权重 | 被站内链接越多,越被认为重要 | 节点大小=入链数的链接图 |
| 锚文本 | 链接上显示的文字 | 指向某页的锚文本分布饼图 |
| nofollow | 告诉搜索引擎不传递权重 | 链接上的小标记 |
| 链接指向重定向 | 内链指向会跳转的 URL,浪费抓取 | 汇总成"一个目标,N 个页面在用" |

## 误报与可信度(新手最容易被吓到)

| 概念 | 一句话解释 | 可视化建议 |
|---|---|---|
| 疑似拦截 | 网站对爬虫做了防护,结果不可信 | 灰色"无法判断"标签,不当错误计数 |
| 瞬时失败 | 同一链接这次失败、下次成功 | 重试记录:第 1 次失败,第 2 次 200 |
| 反爬站点 | LinkedIn、Facebook 常对工具返回 0/400 | 单独归类,不进死链数 |
| 扫描范围限制 | 只爬了 50 页,结论会变 | 页面顶部常驻提示条 |

## 产品形态

建议每个问题都用同一个"卡片"来展示:

1. **这是什么**(一句话,不超过 20 字)
2. **为什么重要**(对排名、收录、体验的影响)
3. **影响多少页**(点开看列表)
4. **怎么修**(具体动作)
5. **可信度**(确定 / 可能 / 无法判断)

第 5 项尤其重要:新手最大的风险是把误报当真,花时间修不存在的问题。
